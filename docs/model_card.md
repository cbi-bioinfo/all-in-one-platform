# 모델 카드 — GROVER Toxicity Predictor 1.0.0

## 1. 모델 개요

| 항목 | 내용 |
|---|---|
| 기술 식별자 | `tox-grover` 1.0.0 |
| 과제 | 화합물 독성 다중작업 이진 분류 — 631개 태스크의 양성 확률 |
| 입력 | SMILES → RDKit 분자 → GROVER 분자 그래프(원자 특징 151차원, 결합 특징 14차원 + 출발 원자 특징) |
| 구조 | GROVER-base 인코더(`dualtrans` 백본, 은닉 800, 메시지 전달 깊이 6, 다중 헤드 어텐션 블록 1개 × 4헤드, PReLU) → 원자 관점·결합 관점 임베딩 각각 평균 readout → 각자의 FFN(800→200→631) → sigmoid → 두 출력 평균. 파라미터 48,963,696개 |
| 사전학습 | 업스트림 GROVER-base(`grover_base.pt`, 논문 기재 약 1,100만 분자 자기지도 학습)에서 시작해 미세조정 |
| 원 논문·코드 | Rong Y. et al., NeurIPS 2020 (arXiv:2007.02835); https://github.com/tencent-ailab/grover (MIT) |
| 가중치 | `models/grover_pretrained.pt` (196 MB) |
| 용도 | 연구용 독성 스크리닝 — 화합물 우선순위 선별 |
| 비용도 | 규제 판단, 임상 의사결정, 실험 독성평가 대체 |

## 2. 학습 데이터 (trainset)

Tox21, ClinTox, ToxCast를 병합하고 canonical SMILES 기준으로 중복을 제거한 10,974 분자 ×
631 태스크 표. 전처리는 RDKit canonical SMILES(염·전하 유지).

* 분할: Murcko scaffold holdout, 분할 seed 2 — train 8,776 / val 1,094 / test 1,104.
* 학습 환경 RDKit(2026.3.6)이 거부하는 `[AlH3]` 알루미늄 착물은 GROVER 데이터 로더가
  자동으로 제외했다(trainset 전체 8개, seed2 train 6개·test 2개).

## 3. 학습 절차 (체크포인트 `args`에 기록된 값)

| 항목 | 값 |
|---|---|
| 시작 가중치 | `grover_base.pt` (구조 관련 하이퍼파라미터는 이 체크포인트에서 상속) |
| 에폭 / 배치 | 30 / 32 |
| 학습률 | Noam 스케줄 — 초기 1e-4, 최대 1e-3, 최종 1e-4, warmup 2 에폭 |
| dropout / FFN | 0.0 / 은닉 200, 2층 |
| 체크포인트 선택 | `seed2_train` 파일을 GROVER가 내부에서 scaffold_balanced 80:20으로 다시 나눠, 그 20%의 AUROC가 가장 높은 에폭 저장 (seed 0) |
| 학습 손실 | 두 헤드 각각의 BCE + 두 헤드 출력 차이 MSE × 0.1 |
| 모델 선정 | 분할 seed 0–4로 학습한 5개 모델 중 **`seedN_val`의 macro AUROC가 가장 높은 seed 2**. 체크포인트 선택은 val 파일을 쓰지 않았으므로 선정 기준과 독립적이다. test로도 seed 2가 가장 높다 |

## 4. 성능

평가 조건: 분할 seed 2의 **test 1,104분자**(학습·체크포인트 선택·모델 선정에 쓰지 않음,
RDKit이 거부한 2분자 제외 1,102분자 채점). 임계값 0.5. test에 양성·음성이 모두 있는
620개 태스크의 지표 단순 평균.

### 4.3 배치 독립 추론과 원본과의 차이

원본 GROVER는 배치 안 각 원자의 이웃 결합 목록을 **배치에서 가장 큰 원자 차수**까지
패딩하고, 패딩 위치의 임베딩이 0이 아니어서 한 분자의 예측이 같은 배치의 다른 분자에
따라 바뀐다. 실측: 배치 크기 1과 32의 차이 최대 0.335.

이 패키지는 분자마다 패딩 폭을 `max(4, 그 분자의 최대 원자 차수)`로 고정했다. 폭 4는
학습 때 크기 32 배치의 약 95%에서 쓰인 값이다. 그 결과:

* 배치 구성·순서·청크 크기와 무관하게 같은 결과(실측 최대 차이 4×10⁻¹⁶, 시험 사례 S13).
* 학습 환경 방식(크기 32, 파일 순서) 출력과 비교하면 1,102분자 중 1,006분자는 6×10⁻⁷
  이내로 같다. 학습 환경에서 원자 차수 5–6 분자와 같은 배치에 들었던 96분자는 최대
  0.305 차이가 나며, 이 때문에 AUROC가 0.6360 → 0.6411로 달라졌다.

## 5. 적용 한계 및 주의사항

1. **제한적 성능과 낮은 민감도.** 0.5 기준으로 양성을 거의 판정하지 않는다(Tox21 민감도
   0.004). ClinTox 태스크는 무작위 수준이다. 확률은 순위화에만 쓴다.
2. **입체 정보 사용.** 키랄 태그와 결합 입체가 특징에 있어 R/S와 입체 표기 유무에 따라
   예측이 달라진다(시험 사례 B2: 0.025–0.039).
3. **특징 인코딩 범위.** 형식 전하 원-핫이 전하값을 그대로 인덱스로 쓰는 업스트림 구현이라
   +6 이상·−7 이하는 인코딩할 수 없어 `E-INPUT-013`으로 거부하고, −2..+2 밖의 전하와
   원자번호 100 초과 원소는 다른 값과 같은 칸에 들어가 `W-FEAT-002` 경고를 붙인다. 또한
   전하 −1은 업스트림 구현상 '기타' 칸에 인코딩된다(학습과 동일하므로 그대로 둠).
   배위결합 등 비표준 결합은 결합 유형 특징이 0이 되어 `W-FEAT-001`.
4. **수소만 있는 분자**(`[H][H]`)는 GROVER가 처리하지 않아 `E-INPUT-012`.
5. **RDKit 버전 의존.** RDKit 2026.3.6의 원자가 규칙을 따른다(시험 사례 S9).
6. **염·전하.** 학습과 같게 기본값은 그대로 둔다. `STANDARDIZE=1`은 예측을 바꾼다
   (시험 사례 S6: 최대 0.020).
7. **적용영역(AD) 판정 없음.** 연구용이며 실험적 독성평가·규제 판단을 대체하지 않는다.

## 6. 재현성

시드 42, 결정적 연산, float64 추론, 배치 독립 패딩. GPU 반복(RTX 2080 Ti / GTX 1080 Ti)과
GPU↔CPU 결과 차이 0(출력 8자리 기준). 허용 오차: 확률 절대오차 1×10⁻⁶, 문자열·라벨 완전
일치. 상세: `docs/selftest_report.md`.
