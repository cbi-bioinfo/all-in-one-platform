# 모델 카드 — ToxKG-GPS Toxicity Predictor 1.0.0

## 1. 모델 개요

| 항목 | 내용 |
|---|---|
| 기술 식별자 | `tox-toxkggps` 1.0.0 |
| 과제 | 화합물 독성 다중작업 이진 분류 — 631개 태스크의 양성 확률 |
| 입력 | SMILES → RDKit 분자 → PyTorch Geometric 그래프 (원자 특징 12, 결합 특징 6, 양방향 간선, self-loop 없음) |
| 구조 | 노드 사영 12→128, 간선 사영 6→128 → GPS 블록 3개 [GINEConv(2층 MLP) + 잔차 + LayerNorm → 분자별 다중 헤드 셀프 어텐션(4헤드, 패딩 마스크) + 잔차 → LayerNorm + FFN(128→256→128, GELU) + 잔차] → 평균 풀링 → LayerNorm + 선형 → 631 로짓, sigmoid. 파라미터 630,263개 |
| 지식그래프 | **사용하지 않음.** ToxKG 저장소의 GPS 모델은 지식그래프(유전자·경로) 노드를 함께 쓰는 Tox21 전용 모델이었고, 플랫폼에서 분자 그래프만 쓰도록 다시 작성해 trainset 631 태스크에 학습했다 |
| 구조 근거 | GPS: Rampášek et al., NeurIPS 2022 / GINE: Hu et al., ICLR 2020 / 출처 저장소: xiejunjie1010-sudo/Molecular-toxicity-prediction (ToxKG) |
| 가중치 | `models/toxkggps_pretrained.pt` (2.5 MB) + `models/toxkggps_pretrained_config.json` |
| 용도 | 연구용 독성 스크리닝 — 화합물 우선순위 선별 |
| 비용도 | 규제 판단, 임상 의사결정, 실험 독성평가 대체 |

### 1.1 원자·결합 특징

| 구분 | 특징 |
|---|---|
| 원자 (12) | 원자번호(정수), 결합 수, 형식 전하, 총 수소 수, 방향족(0/1), 고리(0/1), 혼성 원-핫 6구간(SP, SP2, SP3, SP3D, SP3D2, 기타) |
| 결합 (6) | 결합 유형 원-핫 4(단일, 이중, 삼중, 방향족 — 그 밖은 모두 0), 공액(0/1), 고리(0/1) |

키랄성·동위원소·결합 입체 정보는 없다.

## 2. 학습 데이터 (trainset)

Tox21, ClinTox, ToxCast를 병합하고 canonical SMILES 기준으로 중복을 제거한
10,974 분자 × 631 태스크 표.

* 전처리: RDKit canonical SMILES, 파싱 실패·중복 제거. 염·용매·전하는 제거하지 않음.
* 분할: Murcko scaffold holdout, 분할 seed 0 — train 9,978 / val 490 / test 506.
* 학습 환경의 RDKit(2026.3.2)이 거부하는 8개 분자(`[AlH3]` 알루미늄 착물)는 그래프를
  만들 수 없어 학습에서 빠졌다.
* 결측 라벨은 손실 계산에서 제외(masked BCE)했다.

## 3. 학습 절차

| 항목 | 값 |
|---|---|
| 손실 | 라벨이 있는 (분자, 태스크) 쌍에 대한 이진 교차 엔트로피(로짓 기반) |
| 최적화 | Adam, lr 1e-3, 배치 64, gradient clipping 1.0 |
| epoch | 100 |
| 체크포인트 선택 | 10 epoch마다 val macro AUROC를 계산해 가장 높은 시점의 가중치 저장 |
| 시드 | 42 |
| 모델 선정 | 분할 seed 0–4로 각각 학습한 5개 모델 중 **val macro AUROC가 가장 높은 seed 0** 선정. test macro AUROC로도 seed 0이 가장 높다(4.2절) |

학습 하이퍼파라미터는 플랫폼 학습 스크립트(`scripts/train_gps_bench.py`)의 기본값이며
체크포인트 설정 파일의 구조 값(hidden 128, heads 4, layers 3, dropout 0.1)과 일치한다.
trainset 학습 실행의 명령 기록 자체는 남아 있지 않다.

## 4. 성능

평가 조건: 분할 seed 0의 **test 506분자**(학습·체크포인트 선택·모델 선정에 모두
쓰지 않음). 임계값 0.5. test에 양성·음성이 모두 있는 태스크마다 지표를 계산해
단순 평균(macro)했다.

### 4.3 성능 검증

* 컨테이너 출력으로 계산한 F1·민감도·특이도·평가 태스크 수(551)는 학습 환경(float32)
  재채점값과 같다. AUROC는 0.637418(컨테이너, float64)과 0.637437(학습 환경)로
  1.9×10⁻⁵ 차이 난다. 분자별 확률 차이는 최대 1.4×10⁻⁶, 평균 3.7×10⁻⁸이며 거의 같은
  값들의 순위가 바뀐 결과다. 출력 확률이 0 또는 1에 포화되는 경우는 없었다.
* val 지표 재현: seed 1–4는 저장된 val AUROC와 일치, seed 0은 0.6624(재채점) 대
  0.6623(저장)으로 1×10⁻⁴ 차이. 저장값은 배치 64, 재채점은 배치 256으로 계산했다.
  분자별 어텐션의 패딩 길이가 배치 구성에 따라 달라져 float32에서 미세한 수치 차이가
  생긴다. 본 컨테이너는 float64로 계산하며 서로 다른 GPU와 CPU에서 결과가 같았다.

## 5. 적용 한계 및 주의사항

1. **제한적 성능.** test macro AUROC 0.64(5-seed 0.61 ± 0.02). ClinTox(0.82)와
   Tox21(0.74)은 순위 성능이 나은 편이고 ToxCast(0.63)가 낮다.
2. **임계값 판정 부적합.** 0.5에서 민감도 0.15(Tox21 0.04)로 양성 대부분을 음성으로
   판정한다. `_label`은 참고용이며 확률 순위로 사용한다.
3. **입체이성질체 구별 불가.** 키랄성 특징이 없어 입체 표기만 다른 입력은 같은 확률을
   낸다(시험 사례 B2).
4. **비표준 결합.** 배위결합 등 단일·이중·삼중·방향족 밖의 결합은 결합 유형이 0으로
   인코딩되고 `W-FEAT-001`이 붙는다. trainset에는 이런 결합이 없었다. 같은 금속 착물도
   표기 방식에 따라 예측이 최대 0.34 달라졌다(시험 사례 S10).
5. **원자번호 정수 특징.** 원소가 원-핫이 아니라 원자번호 값으로 들어가므로 학습에
   드문 무거운 원소의 예측은 외삽이다.
6. **RDKit 버전 의존.** RDKit 2026.3.2의 원자가 규칙을 따른다(`[AlH3]` 표기 거부 —
   시험 사례 S9).
7. **염·전하.** 학습과 같게 기본값은 그대로 둔다. `STANDARDIZE=1`은 예측을 크게 바꿀
   수 있다(시험 사례 S6: 최대 0.66).
8. **라벨이 적은 태스크.** 다중작업 모델이라 631개 태스크 모두 확률이 나오지만, 태스크별
   AUROC는 0.0–1.0으로 넓게 흩어져 있고 양성이 적은 태스크의 값은 신뢰도가 낮다.
9. **적용영역(AD) 판정 없음.** 연구용이며 실험적 독성평가·규제 판단을 대체하지 않는다.

## 6. 재현성

시드 42, 결정적 연산, float64 추론. 허용 오차: 확률 절대오차 1×10⁻⁶, 문자열·라벨
완전 일치. 실측값은 `docs/selftest_report.md` 4절.
