# 모델 카드 — SE-MTDNN Toxicity Predictor 1.0.0

## 1. 모델 개요

| 항목 | 내용 |
|---|---|
| 기술 식별자 | `bsp-tox-mtdnn` 1.0.0 |
| 과제 | 화합물 독성 다중작업 이진 분류 — 631개 태스크의 양성 확률 |
| 입력 | SMILES (RDKit canonical) |
| 구조 | ① SE 인코더: GRU 기반 VAE 번역 모델(Winter et al. 2019)의 인코더 평균 μ, 128차원 ② MTDNN: 공유층 128→2048→1024 (BatchNorm, LeakyReLU 0.05) + 태스크별 1024→512→256→1 (BatchNorm, LeakyReLU, sigmoid) × 631 |
| 원 논문·코드 | SE-MTDNN, Sci. Rep. 2023 (doi:10.1038/s41598-023-31169-8), https://github.com/IBM/multitask-toxicity (Apache-2.0) |
| 가중치 | `models/mtdnn_trainset_seed0.pt` (1.68 GB), `models/se_encoder/` (SE 인코더, 원 논문 공개 가중치 그대로 사용) |
| 용도 | 연구용 독성 스크리닝 — 화합물 우선순위 선별, 위험 신호 탐색 |
| 비용도 | 규제 판단, 임상 의사결정, 실험 독성평가 대체 |

## 2. 학습 데이터 (trainset)

Tox21, ClinTox, ToxCast 세 MoleculeNet 데이터셋을 병합하고 canonical SMILES
기준으로 중복을 제거한 다중작업 표.

| | Tox21 | ClinTox | ToxCast | trainset |
|---|--:|--:|--:|--:|
| 분자 수 | 7,831 | 1,461 | 8,577 | **10,974** |
| 태스크 수 | 12 | 2 | 617 | **631** |

* 둘 이상의 데이터셋에 있는 6,519개 분자는 한 행으로 합치고 각 데이터셋의
  라벨을 모두 유지했다. 해당 데이터셋이 다루지 않는 태스크는 결측이다.
* 전처리: RDKit `MolFromSmiles` → `MolToSmiles(canonical=True)`, 파싱 실패와
  중복 제거. **염·용매·전하는 제거하지 않았다**(1,812개 분자가 다중 조각,
  2,583개가 전하 포함).
* 분할: Murcko scaffold 기반 holdout(8:1:1 목표), 분할 seed 0. scaffold가 쏠려
  실제 비율은 train 9,978 / val 490 / test 506이다.
* 출처와 라이선스: `docs/reference_data.md`, `docs/license_confirmation.md`.

## 3. 학습 절차

| 항목 | 값 |
|---|---|
| 손실 | 태스크별 BCE를 라벨 있는 샘플만으로 계산하고 태스크의 학습 라벨 수로 나눠 합산 (결측 라벨 마스킹) |
| 최적화 | Adam, lr 1e-3, ReduceLROnPlateau(patience 5, factor 0.5) |
| 배치 / 최대 epoch | 512 / 50 |
| 체크포인트 선택 | val loss 최소 → **epoch 2** (val loss 15.857) |
| 시드 | 42 |
| 모델 선정 | 분할 seed 0–4로 각각 학습한 5개 모델 중 **val macro AUROC가 가장 높은 seed 0** 선정 (test는 선정에 쓰지 않음) |

학습 하이퍼파라미터는 학습 스크립트(`scripts/train.py`, 원 플랫폼)의 기본값이다.
당시 실행 명령 기록은 남아 있지 않으며, 체크포인트에 기록된 값은 epoch 2와
val loss다. epoch 2에서 val loss가 최소가 되었다는 것은 이후 epoch에서 과적합이
빨리 시작되었음을 뜻한다.

## 4. 성능

평가 조건: 분할 seed 0의 **test 506분자**(학습·체크포인트 선택·모델 선정에 모두
쓰지 않음). 임계값 0.5. 지표는 test에 양성·음성이 모두 있는 태스크마다 계산해
단순 평균(macro)했다. 결측 라벨은 제외했다.

### 4.1 제출 모델

| 지표 | 전체 (551 태스크) | Tox21 (12) | ClinTox (2) | ToxCast (537) |
|---|--:|--:|--:|--:|
| AUROC | **0.6994** | 0.8158 | 0.7238 | 0.6968 |
| F1 | 0.2633 | 0.2543 | 0.4925 | 0.2627 |
| 민감도 | 0.2542 | 0.1917 | 0.4949 | 0.2547 |
| 특이도 | 0.8718 | 0.9824 | 0.4948 | 0.8707 |

Tox21 태스크별 AUROC: NR-AR 0.913, NR-AR-LBD 0.944, NR-AhR 0.800,
NR-Aromatase 0.707, NR-ER 0.720, NR-ER-LBD 0.879, NR-PPAR-gamma 0.714,
SR-ARE 0.799, SR-ATAD5 0.927, SR-HSE 0.781, SR-MMP 0.826, SR-p53 0.778.
ClinTox: FDA_APPROVED 0.793, CT_TOX 0.655.

### 4.2 분할 변동 (5-seed)

같은 방법으로 분할 seed 0–4에서 학습한 5개 모델을 각자의 test로 평가한 값이다.

| 지표 | 평균 ± 표준편차 | seed 0 | seed 1 | seed 2 | seed 3 | seed 4 |
|---|--:|--:|--:|--:|--:|--:|
| AUROC | 0.6743 ± 0.0177 | 0.6994 | 0.6652 | 0.6817 | 0.6524 | 0.6727 |
| F1 | 0.2537 ± 0.0162 | 0.2633 | 0.2552 | 0.2504 | 0.2711 | 0.2285 |
| 민감도 | 0.2478 ± 0.0192 | 0.2542 | 0.2544 | 0.2414 | 0.2702 | 0.2188 |
| 특이도 | 0.8604 ± 0.0155 | 0.8718 | 0.8626 | 0.8595 | 0.8348 | 0.8735 |
| 평가 태스크 수 | | 551 | 611 | 620 | 621 | 611 |

seed 0은 test가 가장 작아(506분자) 평가 가능한 태스크가 가장 적다. 제출 모델의
일반화 성능은 5-seed 평균(AUROC 0.674)을 함께 참고한다.

### 4.3 성능 검증

* 패키지(컨테이너) 추론 결과로 위 지표를 다시 계산해 원 평가 값과 소수점 6자리까지
  일치함을 확인했다(AUROC 0.699450).
* val 지표 재현: 5개 seed 모두 학습 당시 저장된 val AUROC와 일치.

## 5. 적용 한계 및 주의사항

1. **낮은 민감도.** 0.5 임계값에서 민감도가 약 0.25로, 독성 양성의 상당수를 놓친다.
   확률을 순위화·선별에 쓰고 단독 판정 근거로 쓰지 않는다.
2. **태스크별 신뢰도 차이.** 다수의 ToxCast 태스크는 양성 수가 적다. test에서
   태스크별 AUROC는 0.0–1.0으로 넓게 흩어져 있으며(중앙값 0.731, 0.7 이상
   323/551개), 양성이 1–2개뿐인 태스크의 값은 의미가 약하다.
3. **SE 인코더 어휘 한계.** 어휘는 39개 토큰이다. `.`, `/`, `\`, 일부 금속 원소
   기호는 토큰화 단계에서 무시되고 `@` 등은 `<unk>`로 처리된다. trainset의 39%
   (4,271분자)가 이런 손실을 겪었으며 모델은 그 상태로 학습되었다. 입체 표기만
   다른 두 입력의 확률이 크게 다를 수 있다(시험 사례 B2: 최대 0.46). 해당
   입력에는 `W-ENC-001` 경고가 붙는다.
4. **염·전하 처리.** 학습과 같게 기본값은 염·전하를 그대로 둔다. `STANDARDIZE=1`
   (모체 분리·중화)은 예측을 크게 바꿀 수 있다(시험 사례 S6: 최대 0.57).
5. **적용영역(AD) 판정 없음.** trainset과 구조가 크게 다른 화합물(거대고리,
   펩타이드, 무기물, 고분자 등)에 대한 예측의 신뢰도는 검증되지 않았다.
6. **결측 라벨 학습.** 각 분자는 출처 데이터셋의 태스크 라벨만 갖는다. 출처
   데이터셋에 없던 태스크에 대한 확률은 다른 분자들로부터 학습된 값이다.
7. **ClinTox `FDA_APPROVED`** 는 독성이 아니라 승인 여부(양성=승인)다.
8. 연구용이며 실험적 독성평가·규제 판단을 대체하지 않는다.

## 6. 재현성

시드 42, 결정적 연산, float64 추론. GPU 반복 실행과 GPU↔CPU 결과 차이 0
(출력 8자리 기준). 허용 오차: 확률 절대오차 1×10⁻⁶, 문자열·라벨 완전 일치.
