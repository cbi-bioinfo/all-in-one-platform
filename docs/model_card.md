# 모델 카드 — Chemprop Toxicity Predictor 1.0.0

## 1. 모델 개요

| 항목 | 내용 |
|---|---|
| 기술 식별자 | `tox-chemprop` 1.0.0 |
| 과제 | 화합물 독성 다중작업 이진 분류 — 631개 태스크의 양성 확률 |
| 입력 | SMILES → RDKit 분자 → 분자 그래프 (원자 특징 72차원, 결합 특징 14차원) |
| 구조 | Chemprop 2.3.1 D-MPNN: 방향성 결합 메시지 전달(`BondMessagePassing`, 깊이 3, 은닉 300) → 원자 벡터 합/100 (`NormAggregation`) → FFN 300 → 300 → ReLU → 631, sigmoid. 파라미터 507,931개 |

| 구현 | chemprop 2.3.1 소스를 `src/chemprop`에 그대로 포함(MIT). 학습·추론 모두 같은 소스. 추론 래퍼 `src/chemprop_tox`는 본 과제 작성 |
| 가중치 | `models/chemprop_trainset_seed0.pt` (2.06 MB) |
| 용도 | 연구용 독성 스크리닝 — 화합물 우선순위 선별 |
| 비용도 | 규제 판단, 임상 의사결정, 실험 독성평가 대체 |

## 2. 학습 데이터 (trainset)

Tox21, ClinTox, ToxCast를 병합하고 canonical SMILES 기준으로 중복을 제거한
10,974 분자 × 631 태스크 표(`docs/reference_data.md`).

* 전처리: RDKit canonical SMILES, 파싱 실패·중복 제거. 염·용매·전하는 제거하지 않음.
* 분할: Murcko scaffold holdout, 분할 seed 0 — train 9,978 / val 490 / test 506.
* 학습 환경 RDKit(2026.3.6)이 원자가 초과로 거부하는 분자(trainset 전체 8개, `[AlH3]`
  알루미늄 착물)는 학습 전에 제외되었다. seed 0의 val·test에는 해당 분자가 없다.

## 3. 학습 절차

학습 래퍼(`scripts/train_chemprop.py`, 원 플랫폼)가 `chemprop train`을 다음 설정으로 호출했다
(설정값은 `models/chemprop_trainset_seed0_config.json`에 기록).

| 항목 | 값 |
|---|---|
| 과제 유형 | classification (마스킹된 BCE, 결측 라벨 제외) |
| 메시지 전달 | 은닉 300, 깊이 3 |
| FFN | 은닉 300, 1층, dropout 0 |
| 학습 | 50 epoch, 최대 학습률 1e-3(chemprop 기본: 2 epoch 워밍업 후 감소), 배치 64 |
| 시드 | `--pytorch-seed 42`, `--data-seed 42` |
| 데이터 입력 | train 파일 + val 파일 두 개를 넘기고 `--split-sizes 0.9 0.1 0.0` |
| 체크포인트 | chemprop이 선택한 `best.pt` |
| 모델 선정 | 분할 seed 0–4로 각각 학습한 5개 중 **val macro AUROC가 가장 높은 seed 0**. test로도 seed 0이 가장 높다(4.2절) |

**학습 데이터 구성에 관한 주의:** chemprop 2.3.1은 데이터 파일을 두 개 받으면 첫 번째
파일을 `--split-sizes`에 따라 train/val로 나누고(무작위 9:1), 두 번째 파일을 **test**로
쓴다. 따라서 실제 학습에는 trainset 분할의 train 9,978분자 중 약 90%가 쓰였고, 나머지
약 10%(무작위)가 체크포인트 선택용 val로 쓰였다. 플랫폼 분할의 val 490분자는
chemprop 내부에서 test로만 평가되었고, 학습·체크포인트 선택에는 쓰이지 않았다.
seed 선정(위 표)은 이 val 490분자 지표로 했다.

## 4. 성능

평가 조건: 분할 seed 0의 **test 506분자**(학습·체크포인트 선택·모델 선정에 모두 쓰지
않음). 임계값 0.5. test에 양성·음성이 모두 있는 태스크마다 지표를 계산해 단순 평균했다.

### 4.3 성능 검증

* 5개 seed 모두 재채점한 val AUROC가 학습 당시 저장값과 같다.
* 컨테이너 엔진(float64)의 seed0 test 확률은 학습 환경 `chemprop predict`(float32)
  결과와 31만 9천여 개 확률 모두 3.2×10⁻⁷ 이내로 일치한다. 결과 지표는
  `docs/selftest_report.md` 4절.

## 5. 적용 한계 및 주의사항

1. **0.5 임계값 판정 부적합.** 민감도가 낮다(전체 0.22, Tox21 0.09). `_label`은
   참고용이며 확률 순위로 사용한다.
2. **태스크별 신뢰도 차이.** 다수의 ToxCast 태스크는 양성 데이터가 적다.
3. **원자 특징의 원소 범위.** 원자번호 1–36과 I(53)만 개별 비트를 갖고, 그 밖의 원소
   (Pt, Pb, Hg, Sn, Gd 등)는 공통 '기타' 비트로 인코딩된다. 결합 수·형식 전하·키랄
   태그·수소 수·혼성도 정해진 값 밖이면 '기타' 비트를 쓴다. 이런 원자가 있으면
   `W-FEAT-001` 경고가 붙는다.
4. **입체 정보 사용.** 키랄 태그와 결합 입체가 특징에 들어가므로 입체 표기 유무에 따라
   예측이 달라진다(시험 사례 B2). 입체이성질체는 구별되지만, 입체 표기가 빠진 입력은
   입체 미지정 분자로 취급된다.
5. **비표준 결합.** 배위결합(`->`) 등 단일·이중·삼중·방향족이 아닌 결합은 결합 유형
   비트 없이 인코딩되고 `W-FEAT-002`가 붙는다. 같은 금속 착물도 표기에 따라 예측이
   달라진다(시험 사례 S10).
6. **RDKit 버전 의존.** RDKit 2026.3.6의 원자가 규칙을 따른다. `[AlH3]` 알루미늄 착물
   등은 `E-INPUT-002`로 거부된다(시험 사례 S9).
7. **염·전하.** 학습과 같게 기본값은 그대로 둔다. `STANDARDIZE=1`은 예측을 바꾼다
   (시험 사례 S6).
8. **적용영역(AD) 판정 없음.** trainset과 구조가 크게 다른 화합물의 신뢰도는 검증되지 않았다.
9. 연구용이며 실험적 독성평가·규제 판단을 대체하지 않는다.

## 6. 재현성

시드 42, 결정적 연산, float64 추론. 허용 오차: 확률 절대오차 1×10⁻⁶, 문자열·라벨
완전 일치. 실측값은 `docs/selftest_report.md` 4절.
