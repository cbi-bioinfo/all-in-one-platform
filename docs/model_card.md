# 모델 카드 — SSL-GCN Toxicity Predictor 1.0.0

## 1. 모델 개요

| 항목 | 내용 |
|---|---|
| 기술 식별자 | `tox-sslgcn` 1.0.0 |
| 과제 | 화합물 독성 이진 분류 — 태스크별 모델 601개, 각 태스크의 양성 확률 |
| 입력 | SMILES → RDKit 분자 → DGL 그래프 (self-loop 포함, 노드 특징 74차원 `CanonicalAtomFeaturizer`, 결합 특징 없음) |
| 구조 | 태스크마다 GCN 6층(은닉 64, 이웃 합산 GraphConv·정규화 없음, ReLU, BatchNorm, dropout 0.042) → 가중합+최대 readout(128) → MLP(512, ReLU, BatchNorm) → 1 출력, sigmoid (dgllife `GCNPredictor`). 모델 하나당 파라미터 94,018개 |
| 학습 방법 | Mean Teacher 반지도학습: 라벨 있는 분자로 지도 손실, 같은 태스크에 라벨이 없는 trainset 분자로 일관성 손실(학생·교사 출력의 MSE). 제출 가중치는 **teacher** 모델 |
| 원 논문 | Chen J. et al., "Chemical toxicity prediction based on semi-supervised learning and graph convolutional neural network", J. Cheminform. 13, 93 (2021), doi:10.1186/s13321-021-00570-8 |
| 구현 | 원 저장소(chen709847237/SSL-GCN)는 평가 코드만 공개하여, 학습 루프는 논문 식·설명으로 재구성했다. 모델 구조·저장 형식은 원 저장소와 같다. 추론 코드는 본 과제에서 dgllife로 새로 작성했다 |
| 가중치 | `models/sslgcn_pretrained.pt` (241 MB) — 601개 태스크 모델(Mean-Teacher teacher)과 공통 설정을 한 파일로 묶음 |
| 용도 | 연구용 독성 스크리닝 — 화합물 우선순위 선별 |
| 비용도 | 규제 판단, 임상 의사결정, 실험 독성평가 대체 |

## 2. 학습 데이터 (trainset)

Tox21, ClinTox, ToxCast를 병합하고 canonical SMILES 기준으로 중복을 제거한
10,974 분자 × 631 태스크 표. 전처리·분할은 SE-MTDNN과 같다.

* 전처리: RDKit canonical SMILES, 파싱 실패·중복 제거. 염·용매·전하는 제거하지 않음.
* 분할: Murcko scaffold holdout, 분할 seed 0 — train 9,978 / val 490 / test 506.
* 태스크마다 train에서 그 태스크의 라벨이 있는 분자는 지도학습, 라벨이 없는 분자는
  비지도(일관성) 학습에 쓰였다.
* 학습 환경의 RDKit(2026.3.1)은 trainset 분자 중 8개(`[AlH3]` 표기의 알루미늄
  착물)를 원자가 초과로 거부하므로 이 분자들은 학습 그래프에서 빠졌다.

## 3. 학습 절차

| 항목 | 값 |
|---|---|
| 최적화 | Adam, lr 0.068, weight decay 0.00095, 배치 512 |
| Mean Teacher | EMA 계수 0.9495, 일관성 가중치 최대 5.27 (램프업 10 epoch), 입력 노이즈 σ 0.027, 비라벨 배치 비율 0.5 |
| 조기 종료 | 최대 500 epoch, 태스크별 val AUROC 기준 patience 30 — val AUROC가 가장 높은 epoch의 teacher 가중치 저장 |
| 시드 | 42 |
| 모델 선정 | 분할 seed 0–4로 각각 학습한 5개 실행 중 **val macro AUROC가 가장 높은 seed 0** 선정. test macro AUROC로도 seed 0이 가장 높다(4.2절) |
| 모델이 없는 태스크 | 30개. seed 0 val 분할에서 해당 태스크 라벨이 한 클래스뿐이거나 거의 없어(양성 0개 20태스크, 라벨 1–3개 등) val AUROC를 계산할 수 없어 체크포인트가 저장되지 않음. 목록: 가중치 묶음의 `tasks_without_model`, serve 모드 `GET /schema` |

하이퍼파라미터는 학습 때 태스크마다 `configure.json`으로 기록되었고 601개 모두 같다
(가중치 묶음의 `config`; 원 논문 NR-AR SSL 최적 설정).

## 4. 성능

평가 조건: 분할 seed 0의 **test 506분자**(학습·체크포인트 선택·모델 선정에 모두
쓰지 않음). 임계값 0.5. test에 양성·음성이 모두 있는 태스크마다 지표를 계산해
단순 평균(macro)했다.

### 4.1 제출 모델

| 지표 | 전체 (534 태스크) | Tox21 (12) | ClinTox (2) | ToxCast (520) |
|---|--:|--:|--:|--:|
| AUROC | **0.5993** † | 0.7552 | 0.7390 | 0.5930 |
| F1 | 0.1540 | 0.0318 | 0.0000 | 0.1574 |
| 민감도 | 0.2649 | 0.0181 | 0.0000 | 0.2716 |
| 특이도 | 0.7544 | 0.9976 | 1.0000 | 0.7479 |

† 본 컨테이너 출력 기준. 출처별 값은 학습 환경 재채점 기준이다(4.3절).

Tox21 태스크별 AUROC: NR-AR 0.908, NR-AR-LBD 0.746, NR-AhR 0.778,
NR-Aromatase 0.767, NR-ER 0.681, NR-ER-LBD 0.679, NR-PPAR-gamma 0.733,
SR-ARE 0.661, SR-ATAD5 0.773, SR-HSE 0.719, SR-MMP 0.855, SR-p53 0.762.

| 지표 | 평균 ± 표준편차 | seed 0 | seed 1 | seed 2 | seed 3 | seed 4 |
|---|--:|--:|--:|--:|--:|--:|
| test AUROC | 0.5834 ± 0.0122 | 0.5972 | 0.5709 | 0.5944 | 0.5825 | 0.5722 |
| test F1 | 0.1476 ± 0.0037 | 0.1540 | 0.1443 | 0.1462 | 0.1468 | 0.1466 |
| test 민감도 | 0.2720 ± 0.0099 | 0.2649 | 0.2796 | 0.2617 | 0.2849 | 0.2688 |
| test 특이도 | 0.7393 ± 0.0110 | 0.7544 | 0.7310 | 0.7430 | 0.7265 | 0.7417 |
| val AUROC (선정 기준) | | **0.6912** | 0.6481 | 0.6620 | 0.6682 | 0.6639 |

모든 seed에서 val AUROC가 test보다 0.07–0.09 높다. 태스크마다 작은 val로 체크포인트를
고르기 때문에 val 수치는 낙관적이며, 성능은 test 값으로 판단해야 한다.

### 4.3 성능 검증과 수치 정밀도

* 컨테이너 출력으로 계산한 F1·민감도·특이도·평가 태스크 수(534)는 학습 환경
  재채점값과 소수점 15자리까지 같다(0.5 임계 판정이 모든 분자·태스크에서 일치).
* AUROC는 0.5993(컨테이너, float64)과 0.5972(학습 환경, float32)로 0.002 차이가
  난다. 분자별 확률 차이는 최대 3×10⁻⁵이지만, 이 모델은 출력이 0 또는 1로 포화된
  값이 많아(5절) float32에서 생기는 동점과 float64에서의 순위가 달라 AUROC만
  바뀐다. 사용자가 받는 값은 컨테이너 출력이므로 이를 대표값으로 쓴다.
* val 지표 재현: 5개 seed 모두 학습 당시 저장된 val AUROC와 일치.

## 5. 적용 한계 및 주의사항

1. **제한적 성능.** test macro AUROC 약 0.60(5-seed 0.58 ± 0.01). Tox21(0.76)과
   ClinTox(0.74)는 순위 성능이 상대적으로 낫고 ToxCast 태스크(0.59)가 낮다.
2. **과신(overconfidence).** test 출력 확률의 25%가 소수점 8자리에서 정확히 0 또는
   1이다. 확률 크기를 보정된 위험도로 해석하지 않는다.
3. **임계값 판정 부적합.** 0.5에서 Tox21 민감도 0.02, ClinTox 민감도 0(두 태스크
   모두 전 분자를 음성 판정)이다. `_label`은 참고용이며 확률 순위로 사용한다.
4. **모델 없는 태스크 30개**는 출력하지 않는다(`GET /schema`의 `tasks_without_model`).
5. **SMILES 표기 민감성.** 원자 특징에 키랄성이 없어 입체이성질체를 구별하지 못한다.
   반면 대괄호로 쓴 원자(예: 입체중심 `[C@H]`)는 수소가 명시적으로 처리되어 '암묵
   원자가' 특징이 0이 되므로, 같은 분자라도 `[C@H](O)`와 `C(O)`의 예측이 크게 다를
   수 있다(시험 사례 B2: 최대 0.91). trainset은 RDKit canonical SMILES였으므로
   입력도 RDKit canonical 형태가 학습 조건과 가장 가깝다.
6. **특징화 범위.** 43개 원소 밖의 원소, 차수 > 10, 암묵 원자가 > 6, 수소 수 > 4,
   SP–SP3D2 밖의 혼성(예: 고립 금속 이온)은 0으로 인코딩되며 `W-FEAT-001`이 붙는다.
   seed0 test에서는 23/506분자(모두 염·이온 포함 다중 조각)에 해당했다.
7. **RDKit 버전 의존.** RDKit 2026.3.1의 원자가 규칙을 따른다. 구버전에서 유효했던
   `[AlH3]` 알루미늄 착물 등은 `E-INPUT-002`로 거부된다(시험 사례 S9).
8. **염·전하.** 학습과 같게 기본값은 그대로 둔다. `STANDARDIZE=1`은 예측을 크게 바꿀 수
   있다(시험 사례 S6: 최대 0.99).
9. **적용영역(AD) 판정 없음.** trainset과 구조가 크게 다른 화합물의 신뢰도는 검증되지 않았다.
10. 연구용이며 실험적 독성평가·규제 판단을 대체하지 않는다.

## 6. 재현성

시드 42, 결정적 연산, float64 추론. 허용 오차: 확률 절대오차 1×10⁻⁶, 문자열·라벨
완전 일치. 실측값은 `docs/selftest_report.md` 4절.
