# 모델 카드 — FP-GNN Toxicity Predictor 1.0.0

## 1. 모델 개요

| 항목 | 내용 |
|---|---|
| 기술 식별자 | `tox-fpgnn` 1.0.0 |
| 과제 | 화합물 독성 다중작업 이진 분류 — 631개 태스크의 양성 확률 |
| 입력 | SMILES → RDKit 분자 → (a) 분자 지문 1,489개 값 (b) 원자 특징 133차원 + 인접 행렬 |
| 구조 | **지문 가지**: MACCS 167 + ErG 441 + PubChem 881 → Linear 512 → ReLU → Linear 300. **그래프 가지**: 8개 주의 헤드(133→60, ELU) 연결(480) → 출력 주의층(480→300) → ELU → log-softmax → 원자 평균. 두 가지를 각각 Linear 300 + ReLU 후 연결(600) → Linear 300 → ReLU → Linear 631 → sigmoid. 파라미터 1,677,011개 |
| 원 논문 | Cai H. et al., "FP-GNN: a versatile deep learning architecture for enhanced molecular property prediction", Briefings in Bioinformatics 23(6), bbac408 (2022), doi:10.1093/bib/bbac408 |
| 구현 | 학습은 원 저장소(idrugLab/FP-GNN)의 코드를 플랫폼에서 포팅해 수행했다. 원 저장소에 라이선스가 없어 제출 패키지에는 그 코드를 넣지 않고, 추론 엔진을 새로 작성해 같은 계산을 재현했다(4.3절 검증). PubChem 지문만 PyBioMed(BSD-3-Clause) 원본을 그대로 포함한다 |
| 가중치 | `models/fpgnn_trainset_seed0.pt` (6.7 MB) |
| 용도 | 연구용 독성 스크리닝 — 화합물 우선순위 선별 |
| 비용도 | 규제 판단, 임상 의사결정, 실험 독성평가 대체 |

## 2. 학습 데이터 (trainset)

Tox21, ClinTox, ToxCast를 병합하고 canonical SMILES 기준으로 중복을 제거한
10,974 분자 × 631 태스크 표.

| | Tox21 | ClinTox | ToxCast | trainset |
|---|--:|--:|--:|--:|
| 분자 수 | 7,831 | 1,461 | 8,577 | **10,974** |
| 태스크 수 | 12 | 2 | 617 | **631** |

* 전처리: RDKit canonical SMILES, 파싱 실패·중복 제거. 염·용매·전하는 제거하지 않음.
* 분할: Murcko scaffold holdout, 분할 seed 0 — train 9,978 / val 490 / test 506.
* 학습 환경의 RDKit(2026.3.6)이 원자가 초과로 거부하는 8개(`[AlH3]` 알루미늄 착물)는
  학습에서 빠져 실제 학습 분자는 9,970개다(체크포인트의 `train_data_size`).
* 출처·라이선스: `docs/reference_data.md`, `docs/license_confirmation.md`.

## 3. 학습 절차

| 항목 | 값 |
|---|---|
| 손실 | 태스크별 BCE-with-logits, 결측 라벨 마스킹 후 평균 |
| 최적화 | Adam, Noam 학습률 스케줄(warm-up 2 epoch, 최고 1e-3, 시작·끝 1e-4) |
| 배치 / 최대 epoch | 50 / 30 (학습 스크립트 기본값) |
| 체크포인트 선택 | epoch마다 val macro AUROC를 계산해 최고 epoch 저장 → seed 0은 **14번째 epoch** |
| dropout | 0 (지문·그래프 모두) |
| 학습 시드 | 0 |
| 모델 선정 | 분할 seed 0–4로 각각 학습한 5개 모델 중 **val macro AUROC가 가장 높은 seed 0** (0.7483) |

배치·시드·학습 분자 수는 체크포인트에 저장된 학습 인자에서 확인했다. 최대 epoch는 체크포인트에
기록되어 있지 않으며 학습 스크립트 기본값이다.

## 4. 성능

평가 조건: 분할 seed 0의 **test 506분자**(학습·체크포인트 선택·모델 선정에 모두 쓰지 않음).
임계값 0.5. test에 양성·음성이 모두 있는 태스크마다 지표를 계산해 단순 평균(macro)했다.

### 4.1 제출 모델

| 지표 | 전체 (551 태스크) | Tox21 (12) | ClinTox (2) | ToxCast (537) |
|---|--:|--:|--:|--:|
| AUROC | **0.7127** | 0.8048 | 0.7686 | 0.7104 |
| F1 | 0.2722 | 0.4393 | 0.4950 | 0.2677 |
| 민감도 | 0.2616 | 0.4011 | 0.5000 | 0.2575 |
| 특이도 | 0.8746 | 0.9583 | 0.4948 | 0.8742 |

Tox21 태스크별 AUROC: NR-AR 0.915, NR-AR-LBD 0.986, NR-AhR 0.822, NR-Aromatase 0.848,
NR-ER 0.722, NR-ER-LBD 0.833, NR-PPAR-gamma 0.686, SR-ARE 0.772, SR-ATAD5 0.832,
SR-HSE 0.723, SR-MMP 0.814, SR-p53 0.706. ClinTox: FDA_APPROVED 0.818, CT_TOX 0.719.
ClinTox의 민감도·특이도 0.5는 두 태스크가 반대로 치우친 평균이다: test 101분자에서 FDA_APPROVED는
모두 양성(승인)으로 판정했고(민감도 1, 특이도 0), CT_TOX는 양성 4개를 하나도 잡지 못했다(민감도 0,
특이도 0.99). 0.5 라벨은 이 두 태스크에서 쓸모가 없고 순위(AUROC)만 의미가 있다.

### 4.2 분할 변동 (5-seed)

| 지표 | 평균 ± 표준편차 | seed 0 | seed 1 | seed 2 | seed 3 | seed 4 |
|---|--:|--:|--:|--:|--:|--:|
| test AUROC | 0.7117 ± 0.0055 | 0.7127 | 0.7184 | 0.7097 | 0.7142 | 0.7036 |
| test F1 | 0.2742 ± 0.0193 | 0.2722 | 0.2593 | 0.2736 | 0.3066 | 0.2593 |
| test 민감도 | 0.2511 ± 0.0210 | 0.2616 | 0.2357 | 0.2423 | 0.2830 | 0.2330 |
| test 특이도 | 0.8820 ± 0.0077 | 0.8746 | 0.8942 | 0.8845 | 0.8789 | 0.8778 |
| val AUROC (선정 기준) | | **0.7483** | 0.7076 | 0.7105 | 0.7186 | 0.7406 |
| 평가 태스크 수 (test) | | 551 | 611 | 620 | 621 | 611 |

seed 간 test AUROC 차이가 작아(표준편차 0.006) 어느 seed를 골라도 일반화 성능은 비슷하다.
test 기준으로는 seed 1이 가장 높지만, test는 선정에 쓰지 않는다는 원칙에 따라 val 기준 seed 0을
제출했다.

### 4.3 성능 검증

* 제출 패키지의 추론 엔진은 원 학습 코드와 같은 계산을 재현한다. trainset 전체 221,699개 원자의
  특징 벡터와 3,000개 분자의 지문이 학습 코드와 완전히 같았고, seed0 test 확률은 학습 코드(float32)
  대비 최대 1.6×10⁻⁶ 차이였다.
* 컨테이너 출력으로 계산한 seed0 test 지표(AUROC 0.712695, F1 0.272238, 민감도 0.261550,
  특이도 0.874613)가 학습 환경 재채점 값과 소수점 6자리까지 같다.
* val 지표 재현: 5개 seed 모두 학습 당시 저장된 val AUROC와 일치.

## 5. 적용 한계 및 주의사항

1. **임계값 판정의 한계.** 0.5에서 전체 민감도 0.26. 확률은 순위화·선별에 쓴다.
2. **태스크별 신뢰도 차이.** test에서 태스크별 AUROC는 0.0–1.0으로 흩어져 있다(중앙값 0.733, 0.7
   이상 338/551개). 양성이 1–2개뿐인 태스크의 값은 의미가 약하다.
3. **결합 없는 원자.** 그래프 주의가 결합된 이웃끼리만 계산되고 자기 자신을 포함하지 않아, 염의
   금속 이온처럼 결합이 없는 원자는 분자 전체에 주의가 균등하게 퍼진다. 학습 때와 같은 계산이지만
   이온 정보가 흐려진다 — `W-FEAT-002` (trainset 1,359분자).
4. **원-핫 '기타' 칸.** 혼성이 SP–SP3D2 밖(단원자 이온, 명시적 수소, 일부 금속)이거나 결합 수·전하·
   수소 수가 범주 밖인 원자는 '기타' 칸으로 인코딩된다 — `W-FEAT-001` (trainset 516분자).
5. **표기 민감성.** 키랄 태그가 특징에 들어가 입체 표기에 따라 예측이 소폭 달라지고(시험 사례 B2,
   최대 0.0025), 금속 착물은 배위결합 표기 여부에 따라 크게 달라질 수 있다(S10, 최대 0.34).
6. **RDKit 버전 의존.** RDKit 2026.3.6의 원자가 규칙을 따른다. `[AlH3]` 알루미늄 착물 등은
   `E-INPUT-002`로 거부된다(시험 사례 S9).
7. **염·전하.** 학습과 같게 기본값은 그대로 둔다. `STANDARDIZE=1`은 예측을 바꾼다(S6, 최대 0.28).
8. **적용영역(AD) 판정 없음.** trainset과 구조가 크게 다른 화합물의 신뢰도는 검증되지 않았다.
9. **ClinTox `FDA_APPROVED`** 는 독성이 아니라 승인 여부(양성 = 승인)다.
10. 연구용이며 실험적 독성평가·규제 판단을 대체하지 않는다.

## 6. 재현성

시드 42, 결정적 연산, float64 추론. GPU 반복 실행과 GPU↔CPU 결과 차이 0(출력 8자리 기준).
허용 오차: 확률 절대오차 1×10⁻⁶, 문자열·라벨 완전 일치. 상세: `docs/selftest_report.md`.
